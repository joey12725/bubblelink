Stick wiring: every wire, in detail

Everything inside the case, from the battery to the ports on its outside walls. Each wire is drawn on its own. Thick red is the main 12 AWG feed, and every return goes back to the BMS P− bus (black). The coloured tags are plugs: XT30JST-XHXT60H and ports on the outside of the case. For one line per connection, see page 4. For the battery's solder points, see page 5.

12 AWG main + P− return bus 16 AWG pairs thin: 5 V, sensor, pump, voltmeter, balance

The main + path

  • Pack + bus (battery row B) soldered to KEY pin A. Pin B soldered to a lead that clamps into the breaker. These two 12 AWG wires stay connected, so the cap lifts off on a tether: leave enough slack to set it beside the stick.
  • Breaker out → + splice. The ACS758, Buck A, Buck B and the voltmeter all tap off here.
  • ACS758 IP+ in → IP− out → the two gun + leads. Only gun current goes through the sensor. Both of its big wires go on one XT60H (in on one pin, out on the other), so the sensor unplugs in one go.
  • The charger plugs straight into the pack, before the key, so it charges with the key out.

Every − goes to BMS P−

The return bus starts at the BMS P− pad, not the battery's − bus. That includes the charger's black. Otherwise the BMS can't protect the pack. Page 5 shows the pads.

Wiring the current sensor

The sensor itself measures both directions, but the control board only reacts when its signal rises above the resting 2.5 V, which is current flowing in at IP+ and out at IP−. Both big wires are on the + line (red and red): one in from the splice, one out toward the guns. No black wire touches the big terminals.

The wire from IP− goes to the gun breakout, where the two guns' + wires meet. It never goes to the main + splice, or the current would bypass the sensor and it would read nothing.

If the guns run but the yellow GUN LED never lights, swap the two big wires. With RV1's range starting at 2.50 V, a backwards sensor can't be tuned around.

The control board's plugs

J1, J2 and J3 are wires soldered straight onto the board's pads, each ending in a female plug. They plug directly into male ones.

  • J1: red +5 V on pin 1, black GND on pin 2, soldered at Buck A. Set the buck to 5.0 V before you plug it in.
  • J2: red +5 V out to the sensor, black GND, yellow OUT. The plug pushes straight onto the ACS758's signal header pins.
  • J3: red PUMP+, black PUMP−. The pump's black is switched by the board: never join it to the P− bus.
